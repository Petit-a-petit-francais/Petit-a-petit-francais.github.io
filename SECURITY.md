# Security policy

## Supported versions

Only the live site, https://petitfrench.parsakp.com/, and the latest code on `main` get security fixes.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through [GitHub's private vulnerability reporting](../../security/advisories/new).

Include what's affected, steps to reproduce, and the impact you expect. You'll get a reply within 7 days, and a fix or a plan soon after. You'll be credited in the advisory unless you'd rather not be.

## Scope

In scope: the web app in this repo, the sync code (`sync*.js`), and the Google token helper (`token-helper/`).

Out of scope: Google's and Apple's own services, and attacks that need a compromised device or browser.
